# Task Manager

A command-line task management application developed with Python.

## Features

- Add new tasks
- Display all registered tasks
- Remove tasks by their number
- Validate user input
- Handle invalid entries
- Interactive command-line menu

## Technologies

- Python 3
- Built-in Python modules

## How to Run

1. Clone this repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Navigate to the project folder:

```bash
cd task-manager
```

3. Run the application:

```bash
python main.py
```

## How It Works

The application allows users to manage tasks through an interactive terminal menu. Users can add, view, and remove tasks.

Tasks are stored in memory while the application is running. They are not permanently saved.
